# 💡 Ideias

Repositório para organizar ideias por assunto. Cada pasta representa um tema ou projeto.

## Estrutura

```
ideias/
├── <assunto-1>/       # Uma ideia ou tema
│   └── README.md      # Descrição da ideia
├── <assunto-2>/       # Outra ideia ou tema
│   └── README.md      # Descrição da ideia
└── ...
```

## Como usar

1. Crie uma nova pasta com o nome do assunto ou ideia
2. Dentro dela, descreva a ideia em um `README.md`
3. Adicione arquivos conforme necessário (esboços, referências, imagens, etc.)
