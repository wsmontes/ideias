## 1. Why Notion/Obsidian Matters for Feedmine's Routine Loop

Feedmine asks: *"How does accumulated daily behavior reveal patterns the user couldn't see in real-time?"*

Notion/Obsidian answers through daily notes: *"What if every day you wrote a few lines, and over weeks, the CONNECTIONS between those entries revealed things you never consciously noticed?"*

| Dimension | Notion/Obsidian Daily Notes | Feedmine |
|-----------|---------------------------|----------|
| Input | User writes daily (active, conscious) | User reads daily (passive observation possible) |
| Pattern detection | Backlinks + periodic reviews reveal themes | Algorithm detects temporal + topic patterns |
| Review cycle | Weekly/monthly/yearly reviews surface insights | Rolling pattern model updates continuously |
| Core philosophy | "Writing reveals thinking" | "Reading patterns reveal interests" |
| Ownership | Local files (Obsidian) / cloud (Notion) | Local-first |
| Routine mechanism | Template → fill → review cycle | Open → read → patterns accumulate |

**The key insight:** Daily notes don't reveal patterns on Day 1, or Day 7, or even Day 14. They reveal patterns at the PERIODIC REVIEW — when you zoom out and see connections across 30, 90, or 365 days. Feedmine's equivalent: showing the user their reading patterns after enough data accumulates.

## 2. How Daily Notes Create Routine Understanding

### 2.1 The Daily Note as Ritual Anchor

The Obsidian daily notes workflow:
1. **Open Obsidian** (same time daily — becomes ritual)
2. **Template auto-generates** (date, prompts, links to week/month)
3. **Fill in minimal prompts** (5 minutes max)
4. **Close** — note accumulates passively

**The key to adherence (from research):** "Automatic generation + minimal friction for additions. Once these became a system, daily notes changed from something I 'had to write' into something I 'actually use'."

**Adherence data:** Weekly review of daily entries increases 30-day adherence by 42% versus paper journaling (Journal of Behavioral Medicine, 2023).

### 2.2 The Template as Friction Reducer

A typical minimal daily template:
```
## {{date}}
### Energy: /5
### Top 3 today:
1. 
2. 
3.
### Noted:
- 
### Grateful for:
-
```

**Why templates work:**
- Removes "blank page" paralysis (like Daylio's emoji selection)
- Creates consistent data structure → enables pattern analysis
- Takes 2-5 minutes to complete (Daylio-level speed for written journal)
- Same prompts daily = comparable data across days

### 2.3 Periodic Reviews (Where Patterns Emerge)

The multi-level review system:

| Level | Frequency | Purpose | Insight Type |
|-------|-----------|---------|-------------|
| **Daily** | Every day | Capture the moment | Raw data |
| **Weekly** | Every Sunday | "What mattered this week?" | Short-term patterns |
| **Monthly** | 1st of month | "What themes emerged?" | Medium-term trends |
| **Quarterly** | Every 3 months | "Am I heading where I want?" | Direction assessment |
| **Yearly** | December/January | "Who was I this year?" | Identity-level insight |

**How weekly review works in Obsidian:**
- Template auto-generates, pre-filled with Dataview queries
- Shows: all tasks completed, themes mentioned, moods logged
- Surfaces: "This week you mentioned 'burnout' 4 times" (automated)
- The user DISCOVERS patterns they didn't notice in daily living

### 2.4 Backlinks as Unconscious Pattern Detection

Obsidian's graph of connections:
- Every time you mention [[project-X]] in a daily note, it creates a backlink
- After 30 days: the backlinks page for "project-X" shows EVERY day you thought about it
- This reveals: how often something occupied your mind, when it peaked, when it faded

**The unconscious pattern:** You didn't intentionally track "how often I think about project-X" — you just mentioned it when relevant. The tool tracked for you. The REVIEW reveals: "You mentioned burnout 12 times in March, 3 times in April. Something shifted."

## 3. What Feedmine Can Learn

### 3.1 Highest-Priority Transfers

**1. The Periodic Reading Review**
- After 7 days: "This week you read 12 articles. 8 were about AI. 3 were about climate."
- After 30 days: "This month's reading shifted from AI to psychology."
- After 1 year: "Your 2026 reading year: themes, top sources, deepest dives"
- Not mandatory — available for users who want to reflect on their reading

**2. Backlinks as Topic Threading**
- Every article tagged with topics (AI, Climate, Design...)
- A "topic page" shows every article you've read on that topic
- Reveals: how deep you've gone, what sources you prefer, when interest peaked
- Equivalent of Obsidian's backlinks page — but for reading behavior

**3. The Template-as-Ritual Concept**
- Obsidian: same template every day = consistent routine entry point
- Feedmine: same home screen every day = consistent reading entry point
- The "Today tab" (from Headspace loop) is Feedmine's template
- Predictable structure → minimal cognitive load → becomes automatic

**4. The Review as Revelation (Not Prescription)**
- Obsidian reviews SHOW patterns — they don't say "you should write more about X"
- Feedmine reviews should SHOW reading patterns — not say "you should read more of X"
- "Here's what you read this month" ≠ "Here's what you should read next month"
- The user draws their own conclusions (like Daylio's approach)

**5. The Daily → Weekly → Monthly Pyramid**
- Daily: just read (no reflection needed)
- Weekly: optional "Your week in reading" summary
- Monthly: "Your month's reading themes" visualization
- Yearly: "Year in Reading" comprehensive review
- Each level is opt-in — the daily level requires zero effort from user

### 3.2 Design Philosophy Transfers

**6. Accumulated Data > Single Insight**
- One daily note = meaningless. 30 daily notes = a month of your life.
- One article read = data point. 100 articles = reading identity.
- Value INCREASES with time — the app gets better the longer you use it
- Communicate this: "Keep reading. Your patterns are forming."

**7. Local-First = Trust = Sustained Use**
- Obsidian's USP: your data is local Markdown files YOU own
- Feedmine: reading data never leaves device
- Both create trust that enables long-term use (years, not weeks)

**8. Structure Without Rigidity**
- Obsidian: template exists but you can write anything
- Feedmine: "Daily 3" exists but full feed always available
- Provide scaffolding for those who want it; freedom for those who don't

**9. Connection Reveals Meaning**
- Obsidian: linked notes reveal unexpected connections between ideas
- Feedmine: articles on similar themes over time reveal evolving interests
- "3 months ago you started reading about neural interfaces. Now it's 30% of your feed."
- The CONNECTION across time is the insight, not any single article

## 4. Key Differences

| Notion/Obsidian | Feedmine |
|----------------|----------|
| Active input (user writes) | Passive input (user just reads) |
| User does the analysis (reviews) | System does the analysis (ranking + optional review) |
| Text-based (infinite flexibility) | Structured (articles from feeds) |
| PKM tool (knowledge management) | Content delivery (reading experience) |
| Requires significant setup | Should require zero setup |
| Power user audience | Everyone audience |

---

## 5. Summary: The "Routine as Reflection" Philosophy

1. **Daily ritual + periodic review = self-knowledge.** Small daily inputs compound into deep understanding only when periodically reviewed at a higher level.

2. **Patterns emerge from consistency, not from analysis.** You don't need to TRY to discover patterns. Just do the daily thing. The patterns form themselves over time.

3. **The tool should make the invisible visible.** What Obsidian backlinks do for thinking (show connections), Feedmine should do for reading (show patterns, themes, evolution).

4. **Reflection is optional but transformative.** Not everyone will review their reading patterns. But for those who do, it deepens the relationship with the tool enormously.
