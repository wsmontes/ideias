# UX/UI Loop 07 — Tecnobrega & Design Vernacular: O Que a Periferia Ensina Sobre UX Que Bauhaus Nunca Soube

> **Data:** 2026-07-02
> **Loop:** 7 de ∞
> **Tema:** Seis loops de design europeu e americano. Hora da virada. O tecnobrega (Belém do Pará, anos 2000) não é "música brega com sintetizador" — é um MODELO DE NEGÓCIO, um SISTEMA DE DISTRIBUIÇÃO e uma FILOSOFIA DE DESIGN que funcionou SEM indústria, SEM gravadoras, SEM copyright. E a gambiarra brasileira não é "jeitinho" — é uma EPISTEMOLOGIA de design que o Vale do Silício nunca entendeu.

---

## 0. Por Que o Tecnobrega Está Neste Loop

O tecnobrega resolveu, na PRÁTICA e sem teoria, problemas que os design systems dos loops anteriores AINDA não resolveram:

| Problema | Solução Bauhaus/Rams/Ive | Solução Tecnobrega |
|---|---|---|
| **Distribuição** | App Store (30% de taxa) | Camelôs, MP3 no pendrive, 4Shared |
| **Monetização** | Assinatura / Anúncios | Show ao vivo, "shout-outs" pagos |
| **Copyright** | DMCA, DRM, licenças | "Pode copiar." A cópia É o marketing. |
| **Engajamento** | Gamificação, notificações | Aparelhagem: 15.000 pessoas numa festa |
| **Ferramentas** | MacBook Pro + Sketch/Figma | PC de sucata + Fruity Loops |
| **Escala** | App Store global | 700 aparelhagens, R$8M/mês, Belém |

O tecnobrega é um DESIGN SYSTEM para música. E ensina mais sobre produto digital do que muito case study do Vale.

## 1. O Modelo Tecnobrega: 5 Lições de Produto

### Lição 1: O Produto É GRÁTIS. A Experiência É PAGA.

No tecnobrega, o CD custa R$5 e é COPIADO livremente. O artista GANHA dinheiro com o SHOW — que cobra ingresso, vende bebida, recebe "shout-outs" pagos (alguém paga para o DJ gritar seu nome no meio da festa).

**No mobile:** freemium. O app é GRÁTIS (WhatsApp, Instagram, TikTok). A receita vem de ANÚNCIOS, ASSINATURAS PREMIUM ou COMPRAS DENTRO DO APP. O produto é GRÁTIS. A experiência premium é PAGA.

O tecnobrega ENTENDEU isso em 2002 — anos antes do "freemium" ser um termo no Vale.

### Lição 2: Distribuição PEER-TO-PEER, Não Top-Down

No tecnobrega, a distribuição é HORIZONTAL: camelôs copiam CDs, MP3s circulam em pendrives, MSN Messenger, 4Shared, YouTube. Não há "App Store." Não há gatekeeper. Qualquer um pode DISTRIBUIR.

**No mobile:** o sonho do "sideloading" (Android) e o pesadelo do "walled garden" (Apple). A Apple cobra 30% e REJEITA apps que não seguem suas regras. O tecnobrega pergunta: e se QUALQUER UM pudesse distribuir seu app?

**O movimento de Fediverse/ActivityPub (Mastodon, Pixelfed) É a resposta tecnobrega às redes sociais:** distribuição descentralizada, sem gatekeeper, sem loja central.

### Lição 3: Remix Como Método, Não Como Crime

O tecnobrega SAMPLEIA tudo. A Gaby Amarantos canta: "Eu vou samplear, eu vou te roubar." Não é "plágio" — é ANTROPOFAGIA (Oswald de Andrade, 1928): devorar o estrangeiro e transformar em algo LOCAL.

**No mobile:** o design system que "sampleia" outro. Material Design "sampleou" o flat design do iOS 7. Fluent "sampleou" ambos. Isso é CRIME ou é CULTURA? O tecnobrega responde: é cultura. Sempre foi.

**Open source é tecnobrega:** copiar código, modificar, redistribuir. O software livre é antropofágico — devora o proprietário e devolve à comunidade.

### Lição 4: Ferramentas de SUCATA, Resultado de PRIMEIRO MUNDO

Os produtores de tecnobrega usavam PCs DESCARTADOS, peças de sucata, Fruity Loops pirata. Muitos não sabiam notação musical. O resultado? Música que tocou para 15.000 pessoas por festa.

**No mobile:** você não precisa de MacBook Pro + Figma + prototipadora para fazer um app. Dá para prototipar no PAPEL. Dá para testar com 5 usuários. Dá para lançar um MVP feio que FUNCIONA.

**A "gambiarra" como método de design:** use o que tem. Não espere o orçamento ideal. Não espere a ferramenta certa. PROTOTIPE com o que está na mesa.

### Lição 5: A Estética "Brega" Como Identidade, Não Como Defeito

"Brega" significa "cafona", "tacky", "de mau gosto." O tecnobrega ABRAÇOU o termo. As aparelhagens são naves espaciais de LED, glitter, pirotecnia — maximalismo DESCONTROLADO. É o OPOSTO do "menos é mais" de Rams.

**No mobile:** nem todo app precisa ser "clean", "minimalista", "white space." Apps podem ser COLORIDOS. Podem ter PERSONALIDADE. Podem ser "brega" — e FUNCIONAR melhor para seu público do que o minimalismo Bauhaus.

**Exemplo:** o Nubank (roxo!) desafiou a estética "bancária" (azul, cinza, séria). O iFood é vermelho-agressivo. O TikTok é SATURAÇÃO TOTAL. Nenhum deles segue Rams. Todos funcionam BRILHANTEMENTE.

## 2. A Aparelhagem Como Design de Interação

A **aparelhagem** é o sistema de som + palco + luz + DJ que faz a festa tecnobrega acontecer. Não é um "show." É uma INSTALAÇÃO INTERATIVA.

**Elementos da aparelhagem como UI:**
- **Som**: 50.000 watts. O grave no peito. Feedback FÍSICO imediato.
- **Luz**: LED, laser, estroboscópico. Cada batida é VISÍVEL. A luz É a interface.
- **DJ como "algoritmo humano"**: o DJ LÊ a pista. Sabe quando acelerar, quando pausar, quando gritar um nome pago. É um algoritmo com INTUIÇÃO.
- **Participação**: o público NÃO é passivo. Dança, canta, sobe no palco, interage com o DJ. A aparelhagem é co-criada pela multidão.

**No mobile:** a aparelhagem é uma METÁFORA para pensar apps como EVENTOS, não como PRODUTOS. Um app não é uma ferramenta estática — é um ESPAÇO que REAGE ao usuário em tempo real. O feed do TikTok É uma aparelhagem: DJ = algoritmo, luz = efeitos, som = música, público = usuários dançando.

## 3. Gambiarra Como Epistemologia de Design (Revisitada)

A gambiarra já apareceu nos loops de attensity (L11). Mas aqui, o foco é: o que a gambiarra ENSINA sobre design de produto digital?

### 3.1 Gambiarra ≠ "Design Ruim"
Gambiarra é DESIGN SITUADO. A solução é FEIA mas FUNCIONA nas condições REAIS: sem dinheiro, sem material, sem tempo. O design Bauhaus é UNIVERSAL ("uma boa forma para todos"). A gambiarra é CONTEXTUAL ("a forma possível AQUI e AGORA").

### 3.2 Gambiarra É Open Source Antes do Open Source
A gambiarra é compartilhada. Você vê a solução do vizinho, COPIA, ADAPTA, MELHORA. O código é ABERTO por padrão — porque todo mundo vê a gambiarra. Não há "propriedade intelectual" da gambiarra.

### 3.3 Gambiarra É Mobile-First Antes do Mobile-First
A gambiarra é feita COM O QUE ESTÁ À MÃO. Se o que está à mão é um celular Android de R$400 com 2GB de RAM, o design TEM que funcionar NESSE dispositivo. A gambiarra é RESPONSIVE por necessidade, não por filosofia.

### 3.4 Gambiarra É Acessível por Natureza
A gambiarra é VISÍVEL. Você VÊ como foi feita. Os materiais são RECONHECÍVEIS (garrafa PET, arame, fita isolante). Isso é uma LIÇÃO de usabilidade: quando o usuário ENTENDE como algo foi feito, ele CONFIA mais.

## 4. Folclore e Design Systems: O Que as Lendas Ensinam Sobre Componentes

Todo design system tem seus "componentes": botões, cards, modais. Mas o folclore brasileiro TEM "componentes" há séculos:

| Personagem do Folclore | Lição de UX |
|---|---|
| **Saci-Pererê** (uma perna só, redemoinho) | **Acessibilidade**: design deve funcionar para corpos DIFERENTES. Uma perna só não impede o Saci. |
| **Curupira** (pés virados para trás) | **Navegação não-linear**: às vezes o caminho "certo" é o que parece "errado." Os pés do Curupira despistam — como um breadcrumb trail. |
| **Boitatá** (cobra de fogo) | **Dark mode** com BRILHO. Iluminação adaptativa. Protege a floresta. |
| **Iara** (canto que seduz) | **Onboarding**: a interface que ATRAI o usuário para dentro do app. Mas cuidado: pode afogar. |
| **Boto** (sedutor que vira homem) | **Dark patterns**: o botão que parece uma coisa mas É outra. O boto ENGANOU a moça. O dark pattern ENGANOU o usuário. |
| **Mula-sem-cabeça** (galopante, em chamas) | **Loaders e empty states**: o que aparece quando algo deu MUITO errado? Como você lida com a "mula-sem-cabeça" do seu app? |

**Lição:** o folclore é um DESIGN SYSTEM NARRATIVO. Personagens são COMPONENTES reutilizáveis que carregam SIGNIFICADO cultural. O UX designer pode aprender com o folclore: componentes não são só "UI" — são HISTÓRIAS que o usuário já conhece.

## 5. Tropicalismo e UX: A Antropofagia Como Método de Design

O Tropicalismo (1967-1968) e a Antropofagia (1928) são os movimentos culturais mais importantes do Brasil. E sua mensagem central é RELEVANTE para design:

**"Só a Antropofagia nos une."** (Oswald de Andrade)

Não se trata de REJEITAR o design europeu (Bauhaus, Rams, HIG). Nem de COPIÁ-LO. Trata-se de DEVORÁ-LO. Digerir. Transformar em algo LOCAL.

**Antropofagia aplicada a UX:**
- Você usa o grid da Bauhaus? SIM. Mas com cores brasileiras.
- Você usa os princípios de Rams? SIM. Mas para resolver problemas BRASILEIROS (zero-rating, Pix, WhatsApp como infraestrutura).
- Você usa o Material Design? SIM. Mas com tipografia que funciona em português, com ícones que fazem sentido aqui.

**Design Livre (Fred van Amstel):** uma abordagem brasileira de design de interação que "digere" conceitos estrangeiros através da adaptação local. Não é "contra" o design europeu — é CONTRA a IMPORTAÇÃO sem digestão.

## 6. Crítica

1. **Romantização da precariedade.** A gambiarra é CRIATIVIDADE — mas também é SINTOMA de exclusão. O camelô que vende CD pirateado não está fazendo "design vernacular" — está SOBREVIVENDO. Cuidado com o "poverty porn" acadêmico.

2. **Tecnobrega não é "design system."** É uma CENA MUSICAL. Usá-la como "case de UX" é apropriação — reduzir uma cultura viva a "lições de produto."

3. **O folclore como metáfora é FRÁGIL.** Saci não é "acessibilidade." Boitatá não é "dark mode." Essas analogias são DIVERTIDAS — mas superficiais.

4. **Antropofagia pode virar desculpa para cópia.** "Samplear" o trabalho alheio sem crédito, sem pagamento, sem licença — isso não é antropofagia, é EXPLORAÇÃO.

## 7. O Que o Design Vernacular Brasileiro Ensina ao Mobile (Resumo)

| Lição | Aplicação |
|---|---|
| O produto é GRÁTIS, a experiência é PAGA | Freemium, assinatura, compras in-app |
| Distribuição HORIZONTAL | Sideloading, Fediverse, P2P, web apps |
| Ferramentas de SUCATA | MVP, prototipação barata, build com o que tem |
| Remix como MÉTODO | Open source, fork, "samplear" é cultura |
| Estética LOCAL | Nem todo app precisa ser "minimalista" — pode ser "brega", colorido, regional |
| Gambiarra como DESIGN SITUADO | Projete para o dispositivo REAL do usuário, não para o iPhone 15 Pro Max |
| Antropofagia como MÉTODO | Devore os design systems estrangeiros. Transforme em algo brasileiro. |
