> **Data:** 2026-07-02

Ferramentas de AI como v0, Lovable, Google Stitch, Figma Make e Cursor estão transformando "descreva uma tela de login" em código React funcional em SEGUNDOS. ## 2. O Novo Papel do Designer: De "Maker" a "Director"

**Punchcut (2026):**
> "Designers who have built their identity around craft execution are being asked to operate more like a creative director who sets direction, evaluates AI-generated outputs, and makes judgment calls that no algorithm can make."

**O que MORREU:**
- Passar 3 horas ajustando padding de 40 cards no Figma
- Refazer o mesmo componente 5x porque "não ficou bom"
- Produzir "drafts" que um dev vai jogar fora e refazer do zero

**O que NASCEU:**
- **Prompt → 5 variações em 30 segundos.** Você ESCOLHE a melhor.
- **Você define a ESTRATÉGIA.** A AI executa o TÁTICO.
- **Você avalia QUALIDADE.** A AI gera QUANTIDADE.
- **Você decide ÉTICA.** A AI não sabe o que é justo.

**Miguel Luis Ablaza (Abnormal AI):**
> "I'm not focusing on static mockups. I'm bringing prototypes to the table at an earlier rate, and I'm able to think more about the systems and behaviors rather than the visuals."

## 3. "Vibe Design" — O Novo Paradigma

**"Vibe coding"** (Andrej Karpathy, 2025): descreva o que você quer em linguagem natural. Aceite o código gerado. Se quebrar, descreva o erro. Repita.

**"Vibe design"** (2026): o equivalente para UI. "Uma tela de login com e-mail, senha, 'esqueci minha senha', botão 'entrar' com gradiente azul → roxo, e fundo com ilustração abstrata." A AI GERA. Você AVALIA.

**A diferença crucial:** "vibe design" sem CRITÉRIO gera lixo. Com CRITÉRIO (design tokens, componentes, guia de estilo), gera MAGIA.

**O workflow real:**
1. **Prompt inicial** → AI gera 5 versões
2. **Você escolhe 1 direção** → AI refina
3. **Você aponta 3 problemas** → AI corrige
4. **Você aprova** → AI exporta para código

**A regra de ouro:** *"Treat AI-generated output as a high-fidelity wireframe with incorrect design decisions embedded in it."*

## 4. Design Systems Como "Prompt Libraries"

**UXMatters (maio 2026):** Design systems precisam EVOLUIR para a era AI:

| Antes (2020) | Agora (2026) |
|---|---|
| Documentação para HUMANOS | Documentação para MÁQUINAS (machine-readable) |
| Componentes estáticos | Componentes com regras de MONTAGEM |
| Tokens de cor e espaço | Tokens + camada de RACIOCÍNIO (por que esta cor?) |
| Figma como fonte da verdade | Design system como API que AI CONSULTA |

**O futuro:** "Design Systems as prompt libraries for Generative UI via MCPs." Seu design system vira um CONTEXTO que a AI CARREGA antes de gerar qualquer tela.

## 5. Os Riscos (O Que Pode Dar Errado)

| Risco | Detalhe |
|---|---|
| **AI drift** | A AI gera variações SUTILMENTE erradas. Com o tempo, a marca se DILUI |
| **92% de vulnerabilidades** | Código gerado por AI tem falhas de segurança (Smashing Magazine, 2026) |
| **4x mais duplicação** | AI duplica código. Manutenção vira PESADELO |
| **Acessibilidade ILUSÓRIA** | A UI PARECE acessível. Mas o HTML não tem semântica. VoiceOver NÃO funciona |
| **Morte do aprendizado** | Designer júnior não aprende CRAFT — só aprende a dar PROMPT |
| **Monocultura visual** | Se todo mundo usa os mesmos prompts, a internet vira "um shopping bege corporativo gigante" |

## 6. O Que NÃO Muda (As Constantes)

1. **GOSTO.** AI não tem bom gosto. Você tem. (Ou deveria ter.)
2. **EMPATIA.** AI não sabe como seu USUÁRIO se sente. Você precisa saber.
3. **ÉTICA.** AI não sabe o que é justo. Você precisa decidir.
4. **CONTEXTO.** AI não conhece a CULTURA do seu usuário, o NEGÓCIO do seu cliente, as RESTRIÇÕES do seu time.
5. **"Nunca envie código que você não entende."** (Smashing Magazine) Se você não sabe explicar COMO a AI gerou aquilo, NÃO USE.
