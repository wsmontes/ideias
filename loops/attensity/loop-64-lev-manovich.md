## 1. Quem É Lev Manovich

**Lev Manovich** (n. 1960, Moscou) é um teórico da nova mídia e artista digital. Professor no Graduate Center da City University of New York (CUNY). Fundador do Cultural Analytics Lab. Formado em artes visuais, cinema e ciência da computação.

Obras principais: *The Language of New Media* (2001), *Software Takes Command* (2013), *Cultural Analytics* (2020).

Sua pergunta central: **como o SOFTWARE molda a cultura?** Não como "ferramenta neutra" — mas como METAMÍDIA que absorve, transforma e governa todas as outras mídias (texto, imagem, som, vídeo, espaço 3D). O software é o que a eletricidade foi para o século XX — a infraestrutura INVISÍVEL que torna tudo possível.

## 2. Conceitos Fundamentais

### 2.1 Database vs Narrativa (A Lógica do Feed)

Manovich argumenta que o DATABASE (banco de dados) é a forma simbólica dominante da era do computador — assim como a NARRATIVA foi para o romance e o cinema:

> "Como forma cultural, o banco de dados representa o mundo como uma LISTA de itens e se recusa a ordenar essa lista. A narrativa, ao contrário, cria uma trajetória de causa e efeito. Banco de dados e narrativa são INIMIGOS NATURAIS."

**O feed é DATABASE PURO:**
- Posts são ITENS numa lista não-ordenada (ou ordenada pelo algoritmo — não por você).
- Não há TRAJETÓRIA. Não há "começo, meio e fim." Você salta de item em item.
- A experiência do feed é a experiência do DATABASE: busca, filtro, navegação.

**A atenção NARRATIVA vs a atenção DATABASE:**
- Atenção narrativa: LINEAR, CAUSAL, TEMPORAL. "Isto aconteceu, depois isto, depois isto." Você SEGUE um fio.
- Atenção database: ASSOCIATIVA, NÃO-LINEAR, ESPACIAL. "Isto, depois aquilo, depois aquilo outro." Você NAVEGA um espaço.

**O que o feed PERDE ao ser database:**
- A capacidade de CONTAR HISTÓRIAS (L27: voz, L48: memória narrativa).
- A capacidade de CAUSAR TRANSFORMAÇÃO (a narrativa transforma o protagonista; o database transforma... nada. Você é o mesmo depois de 50 posts).

**O que o Liberation Client PODERIA fazer:**
- Reintroduzir a NARRATIVA no database. Não "posts em ordem cronológica" — mas TRAJETÓRIAS. "Esta conversa começou aqui, passou por ali, e terminou aqui." A timeline como NARRATIVA, não como lista.

### 2.2 Interface Separada do Conteúdo

Manovich observa que, na nova mídia, a INTERFACE é SEPARÁVEL do conteúdo:

> "Criar uma obra em nova mídia pode ser entendido como a construção de uma INTERFACE para um BANCO DE DADOS."

O mesmo banco de dados (posts, perfis, conversas) pode ter MÚLTIPLAS interfaces. Uma interface pode gerar ANSIEDADE; outra pode gerar CALMA. O conteúdo é o MESMO; a atenção é DIFERENTE.

**Isso É a justificativa TEÓRICA do Liberation Client:**
- O conteúdo do Mastodon, Bluesky, Nostr é o MESMO. O que MUDA é a interface.
- A interface PADRÃO (feed algorítmico) gera uma atenção ANSIOSA, FRAGMENTADA, RÁPIDA.
- O Liberation Client propõe OUTRA interface — que gera uma atenção CALMA, NARRATIVA, LENTA.
- A MESMA base de dados. OUTRA atenção.

**Implicação radical:** a "economia da atenção" não está no CONTEÚDO (posts, redes sociais) — está na INTERFACE. Mude a interface, mude a atenção.

### 2.3 Software Como Metamídia

Em *Software Takes Command* (2013), Manovich expande: o software não é só uma "ferramenta" — é uma METAMÍDIA. Ele ABSORVE todas as outras mídias e as REMIXA:

> "O software é o motor universal da produção cultural. O que a eletricidade foi para o século XX, o software é para o século XXI."

**O software ABSORVEU a atenção:**
- Antes: livros, teatro, música, conversa — cada um com sua PRÓPRIA atenção.
- Depois do software: TUDO vira "conteúdo" na mesma interface (a tela). A atenção é UNIFICADA — e portanto, CONTROLÁVEL.

**"Cultural software":** Manovich chama de "cultural software" os aplicativos que usamos para CRIAR, EDITAR, COMPARTILHAR e EXPERIMENTAR mídia. Photoshop, After Effects, navegadores, editores de texto, redes sociais. Esse software NÃO É NEUTRO — ele promove certas estéticas e OCULTA outras.

**O feed como "cultural software":**
- O feed promove a estética da MUDANÇA CONSTANTE (L44: velocidade), da SUPERFÍCIE (L14: Han, o liso), da FRAGMENTAÇÃO (L48: memória).
- O feed OCULTA a estética da PROFUNDIDADE, da LENTIDÃO, da NARRATIVA.

### 2.4 A Transição da Criação para a Seleção

Manovich diagnostica uma mudança cultural fundamental:

> "Na nova mídia, há uma transição cultural da CRIAÇÃO para a SELEÇÃO."

**Antes (mídia tradicional):** você CRIAVA. Escrever um texto, pintar um quadro, compor uma música.
**Depois (nova mídia):** você SELECIONA. Escolhe entre opções pré-existentes. "Postar" é SELECIONAR o que escrever entre infinitas possibilidades — e o algoritmo SELECIONA o que mostrar a você.

**A atenção como SELEÇÃO:**
- Sua atenção não CRIA — ela ESCOLHE entre opções dadas pelo database.
- Você não "presta atenção" — você NAVEGA o database.
- A criação exige ATENÇÃO ATIVA. A seleção exige ATENÇÃO REATIVA (L56: James — involuntária).
