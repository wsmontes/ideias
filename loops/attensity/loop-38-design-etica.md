## 0. Crítica do Loop 37

O Loop 37 foi sobre o amor. Mas:

**1. O amor não se PROJETA.** Você pode projetar um app que não atrapalhe o amor — mas não pode projetar o AMOR. O design tem LIMITES (L12, L19). O Loop 37 foi o mais importante e o menos "acionável" de todos.

**2. Trinta e sete loops de diagnóstico e especulação.** Um loop de SÍNTESE PRÁTICA. Isso é 37:1 — desproporcional. Mas este loop tenta equilibrar.

**3. Designers precisam de PRINCÍPIOS, não de filosofia.** Os 37 loops são filosofia. Este loop é princípios. Cada princípio é acionável. Cada princípio tem um "faça" e um "não faça."

## 1. Os 10 Princípios de Design para a Atenção

### Princípio 1: A Atenção É Finita — Projete Para o Fim

**Origem:** L1 (metabolismo), L5 (tempo profundo), L7 (ser-para-a-morte), L24 (morte)

**O princípio:** Toda sessão de atenção DEVE TER UM FIM. O design que não tem fim é EXTRAÇÃO.

**Faça:**
- Paginação com fim explícito. "Você leu tudo. Acabou."
- Sessão com duração máxima, depois da qual o app FECHA.
- Conteúdo que se ESGOTA, não que se RENOVA infinitamente.

**Não faça:**
- Infinite scroll.
- Pull-to-refresh.
- "Veja também", "você pode gostar", "continue lendo."
- Qualquer mecanismo que IMPEÇA o fim natural da sessão.

---

### Princípio 2: A Atenção É Corporal — Projete Para o Corpo, Não Só Para os Olhos

**Origem:** L6 (Merleau-Ponty), L28 (gesto), L30 (respiração), L32 (tato)

**O princípio:** A atenção não está nos olhos — está no CORPO. Um design que imobiliza o corpo é EXTRAÇÃO.

**Faça:**
- Modos de uso para diferentes posturas (caminhando, deitado, sentado).
- Feedback háptico que não é notificação — é PRESENÇA.
- Lembretes de postura, respiração, movimento.
- Interface que funciona com VOZ (L27), não só com texto e toque.

**Não faça:**
- Presumir que o usuário está sentado, imóvel, disponível.
- Usar vibração APENAS para notificações.
- Ignorar que o corpo cansa, dói, tem fome (L22, L23).

---

### Princípio 3: A Atenção É Coletiva — Projete Para o "Nós", Não Só Para o "Eu"

**Origem:** L3 (Durkheim, dia-atenção), L4 (commons), L10 (Krenak), L18 (axé)

**O princípio:** A atenção mais significativa é COMPARTILHADA. Um design que isola é EXTRAÇÃO.

**Faça:**
- Espaços de atenção síncrona (Círculo, Hora do Silêncio, Pacto de Atenção).
- Métricas de COMUNIDADE, não de indivíduo.
- Funcionalidades que funcionam MELHOR em grupo.

**Não faça:**
- Presumir que o usuário está SOZINHO.
- Métricas individuais de "performance" (streaks, rankings).
- Feed personalizado que IMPEDE a experiência compartilhada.

---

### Princípio 4: A Atenção É Afetiva — Projete Para o Cuidado, Não Para a Manipulação

**Origem:** L8 (Spinoza, Ahmed, Brennan), L13 (Freud, Lacan), L37 (amor)

**O princípio:** A atenção é movida por AFETO. Um design que manipula o afeto para extrair atenção é VIOLÊNCIA.

**Faça:**
- Transparência sobre o tom emocional do conteúdo.
- Limites de exposição a conteúdo de alta carga emocional.
- Espaços de restauração afetiva.
- Perguntar: "como você está?" e ADAPTAR a experiência.

**Não faça:**
- Algoritmo que prioriza conteúdo "engajador" (= alta carga emocional negativa).
- Dark patterns que exploram ansiedade, medo, FOMO.
- Notificações que imitam urgência social ("você está perdendo algo!").

---

### Princípio 5: A Atenção É Temporal — Projete Para Múltiplas Escalas de Tempo

**Origem:** L5 (tempo profundo), L16 (geracional), L20 (noite), L29 (ritmo)

**O princípio:** A atenção opera em VÁRIAS escalas de tempo: agora, hoje, esta semana, esta vida, esta geração, esta era geológica. Um design que só opera no AGORA é EXTRAÇÃO.

**Faça:**
- Conteúdo que respeita ritmos (circadiano, semanal, sazonal).
- Memória de LONGO PRAZO (seu jardim em 10 anos, cápsula do tempo).
- Modo "Noite" que efetivamente FECHA o app (L20).

**Não faça:**
- Tudo é "agora", "novo", "urgente."
- Conteúdo antigo tratado como irrelevante.
- Ritmo constante — sem pausas, sem ciclos, sem estações.

---

### Princípio 6: A Atenção É Espacial — Projete Para o LUGAR, Não Para o Não-Lugar

**Origem:** L21 (arquitetura), L36 (clima), L14 (beleza), L32 (tato)

**O princípio:** A atenção sempre acontece num ESPAÇO FÍSICO. Um design que ignora o espaço é EXTRAÇÃO.

**Faça:**
- Adaptar-se ao ambiente (silencioso, barulhento, claro, escuro).
- Perguntar: "onde você está?" e ADAPTAR.
- Celebrar o LUGAR onde o usuário está.
- Beleza como princípio ESTRUTURAL, não cosmético.

**Não faça:**
- Ser climaticamente neutro (mesma luz, mesma temperatura de interface sempre).
- Ignorar que o usuário está num metrô lotado, numa cama, num escritório.
- Design "limpo" que é LISO (Han, L14) — sem textura, sem resistência.

---

### Princípio 7: A Atenção É Generosa — Projete Para a Dádiva, Não Para a Transação

**Origem:** L9 (Weil), L26 (dinheiro), repo Iteração 4 (economia da dádiva)

**O princípio:** A atenção não é uma moeda que se GASTA — é um presente que se DÁ. Um design que trata a atenção como transação é EXTRAÇÃO.

**Faça:**
- "Dar" atenção como ação primária (não "consumir").
- Presentes, não likes: assinados, concretos, custosos (L9, L26).
- Celebrar o que foi DADO, não o que foi ACUMULADO.

**Não faça:**
- Likes anônimos, abstratos, descartáveis.
- Métricas de "engajamento."
- Tratar o usuário como CONSUMIDOR de conteúdo.

---

### Princípio 8: A Atenção É Diversa — Projete Para MUITAS Atenções, Não Para UMA

**Origem:** L11 (gambiarra), L16 (geracional), L18 (Candomblé), L23 (dor), L25 (animal)

**O princípio:** Não existe UMA atenção — existem MUITAS. Um design que presume UM usuário universal é EXCLUSÃO.

**Faça:**
- Modos para diferentes idades (criança, adulto, velho — L16).
- Modos para diferentes condições (dor crônica — L23, baixa visão, baixa alfabetização).
- Permitir que COMUNIDADES definam o que é atenção saudável para elas.
- Interface adaptável a diferentes RITMOS de vida.

**Não faça:**
- Presumir um usuário jovem, saudável, educado, com tempo livre.
- "Simple Mode" como ÚNICA alternativa — é paternalista.
- Ignorar que 2 bilhões de pessoas não têm acesso a água potável (L33) — a atenção DELAS começa com SOBREVIVÊNCIA.

---

### Princípio 9: A Atenção É Silenciosa — Projete Para o Vazio, Não Para o Preenchimento

**Origem:** L2 (Cage, 4'33"), L31 (silêncio), Ma (repo Iteração 2)

**O princípio:** A atenção precisa de VAZIO. Um design que preenche todo o silêncio é EXTRAÇÃO.

**Faça:**
- Espaço BRANCO generoso.
- Pausas ENTRE os conteúdos.
- Fim EXPLÍCITO da sessão.
- Modo Silêncio que efetivamente SILENCIA o app (L31).

**Não faça:**
- "Você pode gostar", "continue lendo", "veja também."
- Preencher TODA a tela com conteúdo.
- Notificações sobre... NADA ("seus seguidores estão com saudades!").

---

### Princípio 10: A Atenção É Sagrada — Projete Com Humildade

**Origem:** L9 (Weil), L10 (Krenak), L18 (Candomblé), L24 (morte)

**O princípio:** A atenção é a coisa mais preciosa que um ser humano pode dar. Um design que não trata a atenção como SAGRADA é PROFANAÇÃO.

**Faça:**
- Perguntar, antes de cada feature: "isto honra a atenção do usuário?"
- Tratar o tempo de atenção como FINITO e SAGRADO.
- O app como SERVIÇO, não como PRODUTO.

**Não faça:**
- "Engajamento" como métrica suprema.
- "Retenção" como objetivo.
- Tratar a atenção do usuário como MEIO para um fim (receita, crescimento, dados).

## 2. O Checklist do Designer Ético

Antes de implementar qualquer feature, responder:

1. Esta feature tem FIM ou é INFINITA?
2. Esta feature RESPEITA o corpo ou o IMOBILIZA?
3. Esta feature CONECTA pessoas ou as ISOLA?
4. Esta feature CUIDA do afeto ou o MANIPULA?
5. Esta feature opera em MÚLTIPLAS escalas de tempo ou só no AGORA?
6. Esta feature RESPEITA o espaço físico ou o IGNORA?
7. Esta feature trata a atenção como DÁDIVA ou como TRANSAÇÃO?
8. Esta feature funciona para MUITOS tipos de atenção ou para UM?
9. Esta feature CRIA vazio ou PREENCHE tudo?
10. Esta feature HONRA a atenção ou a PROFANA?

Se a resposta for a segunda opção em qualquer item: REDESENHE.

## 3. Autocrítica Rápida

**1. Dez princípios é MUITO.** Ninguém vai lembrar de 10 princípios enquanto projeta. Mas cada princípio é uma PERGUNTA, não uma regra. O checklist é o que importa.

**2. "Princípios de design ético" já existem.** Center for Humane Technology, Time Well Spent, IndieWeb. O que este loop acrescenta é a FUNDAMENTAÇÃO — cada princípio é ANCORADO em uma camada dos 37 loops. Não é "opinião" — é SÍNTESE.

**3. Designers não leem loops de 100 linhas.** Este documento existe para ser REFERÊNCIA, não leitura. O checklist de 10 perguntas é a VERSÃO PORTÁTIL.
