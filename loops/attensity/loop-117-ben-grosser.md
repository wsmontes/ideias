## 1. O Demetricador: Remover os Números

O *Facebook Demetricator* (2012) é uma extensão de navegador que REMOVE todas as métricas do Facebook:

> "16 people like this" → "people like this."
> "You have 247 friends" → "You have friends."
> "3 new notifications" → "new notifications."

**O efeito, segundo usuários:**
- Menos COMPETIÇÃO. "Não sei quantos likes os outros têm, então não me comparo."
- Mais ATENÇÃO AO CONTEÚDO. "Comecei a notar QUEM curtiu, não QUANTOS."
- Menos COMPULSÃO. "Sem o número vermelho, não sinto que PRECISO verificar."

**Isso É "Numbers Abstract People" (Princípio 5 do Liberation Client) feito CÓDIGO.** Grosser PROVOU que funciona. O Demetricator é a PROVA DE CONCEITO de que remover métricas MUDA o comportamento.

**Uma rede social DEVERIA ser DEMETRICADA por padrão — não como "opção", mas como ARQUITETURA.**

## 2. Minus: 100 Posts Para a Vida Toda

*Minus* (2023) é a obra mais radical de Grosser: uma rede social onde cada usuário tem 100 POSTS — PARA A VIDA.

> "Infinite social media that centers endless growth gets users focused on growth themselves. Finite social media that centers constraint gets users focused on time, life, play."

**O que aconteceu no Minus:**
- **Mais poesia que política.** Sem métricas para "performar outrage", os usuários filosofam, fazem poesia, refletem.
- **Quase zero trollagem.** Sem "engajamento" para amplificar o dano, trolls "desaparecem muito rápido."
- **Consciência da finitude.** "Você tem 87 posts restantes." Cada post IMPORTA.
- **Desaceleração.** Você PENSA antes de postar — porque cada post é um dos 100.

**Minus é a prova de que DESIGN MUDA COMPORTAMENTO.** As mesmas pessoas que são tóxicas no Twitter se tornam poéticas no Minus. Não é "natureza humana" — é ARQUITETURA DE PLATAFORMA.

## 3. Software Para Menos (Degrowth Aesthetics)

Grosser propõe uma ESTÉTICA DO DECRESCIMENTO (degrowth aesthetics) para software:

> "Today's platforms are engineered for endless growth — more users, more data, more profit. We need software designed for LESS."

**Software para MENOS:**
- Menos MÉTRICAS (Demetricator).
- Menos POSTS (Minus — 100 para a vida).
- Menos VELOCIDADE (não "tempo real" — tempo humano).
- Menos CONTEÚDO (não "infinito" — finito).
- Menos CRESCIMENTO (não "mais usuários" — comunidade sustentável).

**Isso É a FILOSOFIA do Liberation Client traduzida para PRÁTICA ARTÍSTICA:**
- Paginação (50 posts) — MENOS conteúdo.
- Sem infinite scroll — MENOS compulsão.
- Sem métricas — MENOS comparação.
- Session timer — MENOS tempo.
- Cooldown de 24h para seguir — MENOS impulso.

## 4. Go Rando: Ofuscar a Vigilância Emocional

*Go Rando* (2017) substitui sua reação no Facebook por uma reação ALEATÓRIA:

> "It disconnects how we feel from the data that's getting recorded. No longer will my emotions line up neatly with easy analytic pictures of my personality."

**Go Rando é OFUSCAÇÃO como resistência:**
- A plataforma MONITORa suas reações emocionais (L8: afeto — Ahmed, circulação de emoções).
- Go Rando TORNA seus dados INÚTEIS — você parece aleatório, imprevisível.
- É uma tática de GUERRILHA contra a vigilância emocional (L97: Zuboff, capitalismo de vigilância).

**Uma rede social DEVERIA proteger seus usuários da vigilância — não facilitá-la.**

## 5. O Que Uma Rede Social Deveria SER (Segundo Grosser)

**FINITA. SEM MÉTRICAS. LENTA.**

Onde:
- Os NÚMEROS não existem (Demetricator).
- Os POSTS são LIMITADOS (Minus — 100 para a vida, ou 50 por página, ou 3 por dia).
- A VIGILÂNCIA EMOCIONAL é OFUSCADA (Go Rando — a plataforma não sabe o que você sente).
- O CRESCIMENTO não é o objetivo — a SUSTENTABILIDADE é.
- O DESIGN não induz COMPORTAMENTO — ele LIBERTA o usuário para ESCOLHER.
