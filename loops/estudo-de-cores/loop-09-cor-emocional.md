## 0. A Cor Entra Pelos Olhos, Mas Acerta O Hipocampo

~50 milissegundos. É o tempo que a cor leva da retina ao seu sistema límbico — o centro emocional do cérebro. Você SENTE a cor ANTES de saber que viu.

O caminho neurológico:

```
Fóton (380-750nm)
  → Retina (cones L/M/S + bastonetes)
    → Núcleo Geniculado Lateral (tálamo — relay)
      → [VIA RÁPIDA] Amígdala + Hipotálamo (~50ms)
        → Emoção, alerta, frequência cardíaca
      → [VIA LENTA] Córtex Visual V1→V4 (~100-200ms)
        → Reconhecimento, nomeação ("isso é azul")
```

**A via RÁPIDA (retina→amígdala) ativa EMOÇÃO antes da via LENTA (retina→córtex) ativar CONSCIÊNCIA.** Você já está com medo, calmo, excitado ou alerta ANTES de saber POR QUÊ.

Isso significa que a cor do seu app não é "decoração." É uma INTERVENÇÃO NEUROLÓGICA DIRETA. Você está literalmente modulando o estado emocional do usuário via fótons.

## 1. O Modelo Circumplexo de Emoção (Russell, 1980)

### 1.1 As Duas Dimensões

James Russell (1980) propôs que TODAS as emoções humanas podem ser mapeadas em 2 dimensões:

```
                    ALTA ATIVAÇÃO (AROUSAL)
                           ↑
         Alerta            |           Excitação
         Tensão            |           Entusiasmo
         Medo              |           Alegria
                           |
    NEGATIVO ←─────────────┼──────────────→ POSITIVO
    (valência baixa)       |           (valência alta)
                           |
         Tristeza          |           Calma
         Depressão         |           Contentamento
         Tédio             |           Serenidade
                           |
                    BAIXA ATIVAÇÃO (AROUSAL)
```

- **Valência:** quão positiva ou negativa a emoção é (eixo X)
- **Ativação (arousal):** quão energética ou calma a emoção é (eixo Y)

### 1.2 Como Cores Mapeiam Neste Modelo

Estudos psicofísicos (Valdez & Mehrabian, 1994; Ou et al., 2004) mapearam cores no circumplexo:

```
                    ALTA ATIVAÇÃO
                           ↑
          Vermelho puro    |    Laranja vibrante
          (raiva/urgência) |    (alegria/energia)
                           |
    NEGATIVO ←─────────────┼──────────────→ POSITIVO
                           |
          Cinza escuro     |    Azul claro
          (tristeza)       |    (calma/paz)
                           |
                    BAIXA ATIVAÇÃO
```

**Descobertas consistentes (cross-cultural, replicadas):**

| Cor | Valência | Arousal | Emoção dominante |
|---|---|---|---|
| **Azul** (L=0.50, C=0.15, h=250) | Alta (positiva) | Baixa | Calma, confiança, segurança |
| **Verde** (L=0.55, C=0.18, h=140) | Alta | Média-baixa | Natureza, equilíbrio, saúde |
| **Amarelo** (L=0.60, C=0.20, h=90) | Alta | Alta | Alegria, energia, otimismo |
| **Laranja** (L=0.55, C=0.22, h=55) | Alta | Alta | Entusiasmo, criatividade, calor |
| **Vermelho** (L=0.48, C=0.25, h=25) | Variável | **Máxima** | Paixão OU perigo (contexto!) |
| **Roxo** (L=0.45, C=0.20, h=290) | Média-alta | Média | Mistério, luxo, espiritualidade |
| **Cinza neutro** (L=0.50, C=0, h=0) | Neutra | Mínima | Neutralidade, calma, profissionalismo |
| **Preto** (L=0.05) | Média-baixa | Média | Poder, elegância OU luto (cultura!) |
| **Branco** (L=0.98) | Alta | Baixa | Pureza, simplicidade, limpeza |

### 1.3 O Que MUDA com Saturação (Chroma) e Luminosidade

O MATIZ sozinho não determina a emoção. Chroma e Lightness MODULAM a resposta:

| Mesmo matiz, chroma diferente | Emoção |
|---|---|
| Azul C=0.05 (pastel) | Calma suave, relaxamento |
| Azul C=0.15 (médio) | Confiança, profissionalismo |
| Azul C=0.25 (vibrante) | Energia, excitação, "tech" |
| Azul C=0.35 (P3 máximo) | Impacto, futurismo, intensidade |

**Lightness também modula:**
- L alto (>0.80) + C baixo = "suave, seguro, acolhedor"
- L médio (~0.55) + C alto = "vibrante, energético, marcante"
- L baixo (<0.25) + C baixo = "sério, elegante, misterioso"
- L baixo + C alto = "dramático, intenso, noturno"

**A REGRA geral:**
- Mais chroma = mais AROUSAL (excitação)
- Mais lightness = mais VALÊNCIA POSITIVA (até ~0.85, depois vira "estéril")
- Matiz determina o TIPO de emoção dentro do quadrante

## 2. A Neurobiologia da Cor

### 2.1 O Que Acontece no Cérebro

Estudos de fMRI mostram que diferentes cores ativam diferentes regiões:

| Cor | Região ativada | Efeito fisiológico |
|---|---|---|
| **Vermelho** | Amígdala + Hipotálamo | ↑ cortisol, ↑ frequência cardíaca, ↑ pressão sanguínea |
| **Azul** | Córtex pré-frontal | ↓ cortisol, ↓ frequência cardíaca, ↑ ondas alfa (relaxamento) |
| **Verde** | Córtex cingulado anterior | ↓ estresse, ↑ criatividade (estudos de atenção) |
| **Amarelo** | Sistema de alerta (locus coeruleus) | ↑ noradrenalina, ↑ vigilância, ↑ ansiedade se excessivo |

### 2.2 O Efeito Vermelho na Performance

**Elliot et al. (2007):** participantes veem capas de prova vermelhas vs verdes vs cinzas antes de um teste cognitivo. Resultado: o grupo VERMELHO teve performance PIOR.

**Interpretação:** vermelho ativa AVOIDANCE MOTIVATION (medo de falhar). É a cor do "perigo" e do "erro" — condicionada evolutivamente (sangue = ferimento, rostos vermelhos = raiva/ameaça). Expor usuários a vermelho ANTES de tarefas cognitivas piora a performance.

#{% d %}**Hill & Barton (2005):** em lutas de boxe e taekwondo nas Olimpíadas de 2004, competidores vestindo VERMELHO venceram 55-60% das lutas. O vermelho pode INTIMIDAR o oponente.

**Implicação para apps:** vermelho em CTAs de COMPRA funciona por criar urgência. Mas vermelho em apps de PRODUTIVIDADE ou APRENDIZAGEM pode piorar a performance cognitiva.

### 2.3 O Efeito Azul na Criatividade

**Mehta & Zhu (2009):** participantes em salas com fundo AZUL tiveram performance SUPERIOR em tarefas CRIATIVAS (brainstorming, pensamento divergente). Participantes em salas VERMELHAS tiveram performance superior em tarefas ANALÍTICAS (atenção a detalhes, memória).

**Implicação:** apps de design/criação (Figma, Notion, Miro) usam paletas com azul/neutro. Apps de análise/precisão (dashboards financeiros) podem se beneficiar de detalhes em vermelho — mas apenas para ELEMENTOS DE DESTAQUE, não o fundo.

### 2.4 Cor e Ritmo Circadiano

A luz AZUL (460-480nm) suprime a MELATONINA — o hormônio do sono. Isso é MEDIDO e COMPROVADO:

```
Luz azul (460nm):    supressão de melatonina = ALTA (pico de sensibilidade)
Luz verde (530nm):   supressão = MÉDIA
Luz vermelha (620nm): supressão = BAIXA (quase zero!)
```

**iOS Night Shift e Android Night Light** reduzem a luz azul à noite deslocando a temperatura de cor para AMARELO/ÂMBAR (~3200K). Isso NÃO é uma preferência estética — é INTERVENÇÃO NEUROLÓGICA para preservar o ciclo circadiano.

**Implicação para apps:** se seu app é usado à noite (ex: leitor, meditação, chat), ofereça um modo noturno com redução de luz azul. Não basta dark mode — precisa REDUZIR O MATIZ AZUL.

## 3. Como Apps Usam Cor Para Manipular Emoção

### 3.1 Headspace: Baixo Arousal, Alta Valência

**Objetivo emocional:** calma, segurança, mindfulness.

**Paleta:**
```
Laranja pastel: oklch(0.75 0.08 55)   # acolhedor, não energético
Amarelo suave:  oklch(0.80 0.06 90)   # alegria contida
Azul claro:     oklch(0.70 0.05 240)  # calma
Verde menta:    oklch(0.72 0.06 160)  # natureza, equilíbrio
Fundo:          oklch(0.96 0.005 55)  # off-white quente
```

**O que faz:**
- NUNCA usa vermelho. Muito arousal.
- Chroma SEMPRE < 0.10. Cores pastel = baixo arousal.
- Lightness ALTO (>0.65). Clareza = positividade.
- Matizes QUENTES (laranja, amarelo) com baixa saturação = "aconchego sem excitação."
- Ilustrações com formas GORDAS e ARREDONDADAS (não é cor, mas complementa).

### 3.2 Netflix: Alto Arousal, Valência Variável

**Objetivo emocional:** excitação, antecipação, imersão.

**Paleta:**
```
Vermelho Netflix: oklch(0.45 0.25 30)  # urgência, paixão, excitação
Preto profundo:   oklch(0.05 0 0)      # cinema, imersão
Branco:           oklch(0.95 0 0)      # contraste máximo
Cinza de apoio:   oklch(0.30 0 0)      # neutro, não compete
```

**O que faz:**
- VERMELHO como ÚNICA cor de acento. Máximo impacto.
- Preto como fundo = tela de cinema. Você não está "usando um app" — está "assistindo algo."
- SEM outras cores. Netflix não tem "verde sucesso" ou "azul informação." Só vermelho + preto + branco.
- Chroma MÁXIMO no vermelho (0.25) = máximo arousal.
- Gradientes de fundo nos thumbnails: cores VIBRANTES + escuras = "isso é emocionante."

### 3.3 Notion: Médio Arousal, Alta Valência

**Objetivo emocional:** foco calmo, criatividade, confiança.

**Paleta:**
```
Fundo claro:     oklch(0.98 0 0)        # branco quente (não estéril)
Texto:           oklch(0.15 0 0)        # preto suave (não agressivo)
Cinzas:          oklch(0.90 a 0.30)     # escala perceptual neutra
Azul (link):     oklch(0.55 0.15 250)   # confiança, calma
Destaques color: oklch(0.55 0.08 ...)   # cores MUITO sutis (chroma < 0.10)
```

**O que faz:**
- Fundo branco QUENTE (levíssimo tom amarelado) — não é branco frio/estéril.
- Cores de acento com chroma REDUZIDO. Destacam sem excitar.
- Sistema de cores por bloco: cada tipo de bloco (texto, heading, callout) tem uma cor, mas TODAS com baixo chroma.
- O usuário escolhe a cor do bloco — AGÊNCIA = maior valência positiva.
- Dark mode mantém a mesma filosofia: chroma baixo, valência alta.

### 3.4 Calm: Baixo Arousal, Valência Alta

**Objetivo emocional:** sono, relaxamento profundo, segurança noturna.

**Paleta:**
```
Azul noite:    oklch(0.15 0.05 250)    # profundo, seguro, sono
Roxo escuro:   oklch(0.20 0.08 280)    # transição para o sono
Dourado sutil: oklch(0.50 0.06 80)     # toque de calor (raro)
Verde natural: oklch(0.40 0.10 150)    # natureza noturna
```

**O que faz:**
- FUNDAMENTALMENTE dark-first. Light mode nem é opção.
- Sem vermelho, sem amarelo, sem laranja vibrante. Só cores de BAIXO AROUSAL.
- Matizes FRIOS (azul, roxo, verde) dominam. São as cores da noite e do sono.
- Chroma BAIXO. Cores fortes = cérebro desperto.
- Ilustrações de natureza noturna (lua, estrelas, floresta) — a cor REAFIRMA o contexto.

### 3.5 Padrão: A Fórmula Emocional

| Objetivo emocional | Matizes | Lightness | Chroma | Fundo |
|---|---|---|---|---|
| **Calma/foco** (Headspace, Notion) | Quentes (laranja, amarelo) ou neutros | Alto (>0.65) | Baixo (<0.10) | Claro quente |
| **Excitação/energia** (Netflix, TikTok) | Quentes (vermelho, laranja) | Médio-baixo (0.40-0.55) | Alto (>0.20) | Escuro ou vibrante |
| **Confiança/segurança** (bancos, saúde) | Azul, verde | Médio (~0.55) | Médio (0.12-0.18) | Claro |
| **Sono/relaxamento** (Calm, Headspace night) | Frios (azul, roxo) | Baixo (<0.25) | Baixo (<0.08) | Escuro |
| **Luxo/exclusividade** (moda, premium) | Preto, dourado, roxo | Extremos (0.05 ou 0.95) | Muito baixo (<0.05) | Preto |
| **Criatividade/expressão** (Instagram, Behance) | Arco-íris, gradientes | Variado | Alto (>0.20) | Gradiente |

## 4. O Efeito das Cores no Corpo (Psicofísica Medida)

### 4.1 Frequência Cardíaca e Pressão Sanguínea

Estudos controlados (Küller et al., 2009; Al-Ayash et al., 2016):

```
Vermelho:  ↑ FC +5-10 bpm, ↑ pressão sistólica +3-5 mmHg
Azul:      ↓ FC -3-5 bpm, ↓ pressão sistólica -2-3 mmHg
Verde:     ↓ FC -2-3 bpm (efeito menor que azul)
Amarelo:   ↑ FC +2-4 bpm (efeito menor que vermelho)
Cinza:     ↔ sem alteração significativa
```

### 4.2 Performance Cognitiva

**Vermelho:** melhor em tarefas de ATENÇÃO A DETALHES (proofreading, memória de curto prazo). Pior em tarefas CRIATIVAS.
**Azul:** melhor em tarefas CRIATIVAS (brainstorming, associação livre). Pior em tarefas de PRECISÃO.
**Verde:** melhor em tarefas de LONGA DURAÇÃO (menos fadiga mental após 30+ minutos).

### 4.3 Apetite e Cor

| Cor | Efeito no apetite | Marcas |
|---|---|---|
| Vermelho | **AUMENTA** (resposta evolutiva: fruta madura) | McDonald's, KFC, Pizza Hut, Burger King |
| Amarelo | **AUMENTA** (associado a carboidratos) | McDonald's (vermelho + amarelo), Subway, Lay's |
| Verde | NEUTRO (associado a "saudável") | Whole Foods, Sweetgreen |
| Azul | **SUPRIME** (não existe comida azul na natureza) | Quase NENHUMA marca de comida |
| Roxo | **SUPRIME** (raro em comida natural) | Marcas de luxo, não comida |

**O azul SUPRIME o apetite.** Por isso você nunca vê uma lanchonete com logo azul. E por isso apps de dieta (MyFitnessPal, Noom) usam azul e verde, não vermelho.

## 5. Mapeando Emoção Para OKLCH (Ferramenta Prática)

### 5.1 A Função `emotionalPalette(emotion, intensity)`

```javascript
function emotionalPalette(emotion, intensity = 1.0) {
  const presets = {
    calm: {
      hues: [200, 160, 90],        // azul, verde, amarelo suave
      lightnessRange: [0.65, 0.85],  // claro
      chromaRange: [0.03, 0.10],     // baixa saturação
      bg: { L: 0.96, C: 0.003, h: 60 },  // off-white quente
    },
    focus: {
      hues: [250, 140],
      lightnessRange: [0.50, 0.65],
      chromaRange: [0.08, 0.15],
      bg: { L: 0.97, C: 0, h: 0 },
    },
    energy: {
      hues: [30, 55, 340],
      lightnessRange: [0.45, 0.58],
      chromaRange: [0.18, 0.28],
      bg: { L: 0.08, C: 0.005, h: 260 },
    },
    trust: {
      hues: [250, 220, 200],
      lightnessRange: [0.50, 0.60],
      chromaRange: [0.12, 0.18],
      bg: { L: 0.98, C: 0.002, h: 250 },
    },
    luxury: {
      hues: [280, 40, 30],
      lightnessRange: [0.08, 0.25],
      chromaRange: [0.02, 0.08],
      bg: { L: 0.05, C: 0, h: 0 },
    },
  };

  const preset = presets[emotion];
  const palette = preset.hues.map(h => ({
    L: preset.lightnessRange[0] + (preset.lightnessRange[1] - preset.lightnessRange[0]) * 0.5,
    C: (preset.chromaRange[0] + (preset.chromaRange[1] - preset.chromaRange[0]) * 0.5) * intensity,
    h,
  }));

  return { bg: preset.bg, colors: palette };
}
```

### 5.2 Exemplos de Uso

```javascript
// App de meditação: "calm", intensidade 0.7 (ainda mais suave)
emotionalPalette('calm', 0.7);
// → bg oklch(0.96 0.003 60), cores com C < 0.07

// App de fitness: "energy", intensidade 1.2 (ainda mais vibrante)
emotionalPalette('energy', 1.2);
// → bg oklch(0.08 0.005 260), cores com C > 0.22

// App bancário: "trust", intensidade 1.0
emotionalPalette('trust', 1.0);
// → bg oklch(0.98 0.002 250), azuis com C ~0.15
```

## 6. Para Levar Para Casa

1. **Cor atinge o sistema límbico em ~50ms, ANTES do córtex.** Você sente antes de saber que viu. A paleta do seu app é uma intervenção neurológica.

2. **O circumplexo arousal/valência explica TUDO.** Alta ativação = vermelho, laranja, chroma alto. Baixa ativação = azul, verde, pastel. Valência positiva = lightness alto. Valência negativa = lightness baixo ou chroma extremo.

3. **Chroma controla AROUSAL. Lightness controla VALÊNCIA. Matiz determina o TIPO de emoção.** Ajuste cada dimensão com intenção.

4. **Vermelho piora criatividade, melhora atenção a detalhes. Azul melhora criatividade, piora precisão.** Escolha cores baseado na TAREFA do usuário.

5. **Luz azul suprime melatonina.** Apps noturnos devem reduzir matiz azul, não só luminância (dark mode não basta).

6. **Azul suprime apetite.** Apps de comida usam vermelho/amarelo por um motivo neurológico, não estético.

7. **Headspace, Netflix, Notion, Calm — cada um usa uma FÓRMULA emocional diferente.** Você pode fazer o mesmo: escolha a emoção → mapeie para matiz + chroma + lightness.
