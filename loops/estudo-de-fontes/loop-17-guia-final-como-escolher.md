## PASSO 1: Contexto (2 min)

### Onde esta fonte vai VIVER?

| Pergunta | Exemplos de Resposta |
|---|---|
| **Onde?** | App mobile, site desktop, dashboard, poster impresso, livro, logo, terminal de código, outdoor, smartwatch |
| **Quanto texto?** | 5 palavras (logo), 50 palavras (headline + CTA), 500 palavras (landing page), 50.000 palavras (livro) |
| **Quem lê?** | Público geral, desenvolvedores, idosos, crianças, leitores com baixa visão, público internacional |
| **Qual dispositivo?** | iPhone 16 Pro (OLED, 460 PPI), monitor Dell 1080p (LCD, 96 DPI), Kindle (e-ink), TV 4K |
| **Qual idioma?** | Só português, português + inglês, 10+ línguas incluindo árabe e CJK |

**Regras de ouro do contexto:**

- **App mobile → Neo-Grotesca ou Humanista Sans.** Inter, SF Pro, Roboto. x-height alta, apertures grandes.
- **Dashboard / dados → Neo-Grotesca ou Monospace.** Inter, IBM Plex Sans/Mono. Números tabulares, densidade.
- **Site editorial / blog → Serif + Sans pair.** Georgia + Inter, Source Serif + Source Sans. Conforto de leitura.
- **Logo → Display ou Custom.** Não use Inter no logo. Contrate um lettering artist ou use uma display com personalidade.
- **Livro impresso → Serif.** Garamond, Baskerville, Caslon. A tradição existe POR UM MOTIVO.
- **Terminal / código → Monospace.** JetBrains Mono, Fira Code, Cascadia Code.
- **Multilíngue → Noto ou Source.** A única resposta para 10+ scripts.

## PASSO 2: Personalidade (2 min)

### Que EMOÇÃO esta fonte precisa evocar?

| Se você quer... | Categoria | Exemplos |
|---|---|---|
| **Confiança, seriedade, tradição** | Serif (Transicional ou Garalde) | Baskerville, Georgia, Garamond, Caslon |
| **Modernidade, clareza, eficiência** | Neo-Grotesca Sans | Inter, SF Pro, Helvetica, IBM Plex Sans |
| **Calor, proximidade, "humano"** | Humanista Sans | Open Sans, Lato, Frutiger, Proxima Nova |
| **Elegância, luxo, glamour** | Didone | Bodoni, Playfair Display, Didot |
| **Amizade, diversão, infância** | Arredondada ou Casual Script | Nunito, Comic Sans, Lobster, Varela Round |
| **Impacto, urgência, ousadia** | Fat Face ou Condensada Display | Abril Fatface, Bebas Neue, Impact |
| **Tecnologia, precisão, "código"** | Monospace | JetBrains Mono, Fira Code, Source Code Pro |
| **Artesanal, autêntico, "feito à mão"** | Script ou Display Texturizada | Brush Script, Bricolage Grotesque |
| **Medieval, gótico, sombrio** | Blackletter | Fette Fraktur, Cloister Black |
| **Épico, cinematográfico, eterno** | Glyphic | Trajan, Albertus |

**Se você não souber a personalidade, use Inter.** Inter é a "fonte zero" — neutra o suficiente para funcionar em 80% dos contextos. Não é a melhor escolha para nada, mas é uma escolha SÓLIDA para quase tudo. Comece com Inter. Depois troque se precisar de mais personalidade.

## PASSO 3: Categoria (2 min)

### Qual categoria tipográfica serve ao contexto + personalidade?

```
PRECISA DE SERIF?
├── SIM → Quanta autoridade?
│   ├── MÁXIMA (jurídico, acadêmico) → Transicional (Baskerville, Georgia)
│   ├── ALTA (editorial, livro) → Garalde (Garamond, Caslon)
│   ├── MÉDIA (branding, site) → Slab Serif (Archer, Chaparral)

│   └── CALIGRAFIA (convite, certificado) → Glyphic (Trajan) ou Script (Bickham)

└── NÃO → Qual energia?

    ├── QUENTE (site, produto, "humano") → Humanista Sans (Open Sans, Frutiger)
    ├── IMPACTO (poster, hero, evento) → Geométrica (Futura, Montserrat)
    ├── VINTAGE/ESQUISITA (branding ousado) → Grotesca (Franklin Gothic, Akzidenz)
    └── CÓDIGO (terminal, editor) → Monospace (JetBrains Mono, Fira Code)
```

## PASSO 4: Pairing (2 min)

### Preciso de 1 ou 2 fontes?

**90% dos projetos precisam de 1 fonte com múltiplos pesos.**

Se você PRECISA de 2 fontes, siga a regra de ouro do pairing (Loop 06):

> **Diferença de CATEGORIA + semelhança de PROPORÇÃO (x-height)**

**Combos seguros (testados por décadas):**

| Contexto | Headlines (Estrela) | Body (Suporte) |
|---|---|---|
| **Editorial, blog** | Playfair Display | Lato |
| **Landing page moderna** | Fraunces | Inter |
| **Corporativo** | IBM Plex Serif | IBM Plex Sans |
| **App / produto** | Inter Display | Inter Regular |
| **Portfolio criativo** | Bricolage Grotesque | Inter |
| **Moda / luxo** | Bodoni / Abril Fatface | Montserrat Light |
| **Tech / SaaS** | Space Grotesk | Inter |

**Dica:** se você só precisa de 1 fonte, use uma superfamília (IBM Plex, Source, Roboto, DM Sans/Serif) — o pairing já vem PRONTO.

## PASSO 5: Licenciamento (1 min)

### Posso usar essa fonte LEGALMENTE?

| Tipo de Licença | Exemplos | Pode Usar Em |
|---|---|---|
| **SIL Open Font License (OFL)** | Inter, Fira Code, Source Serif, Montserrat, Lato, Open Sans | QUALQUER projeto (comercial, app, web, logo) — sem custo |
| **Apache 2.0** | Roboto, Roboto Flex, JetBrains Mono | Qualquer projeto — sem custo |
| **Google Fonts (OFL)** | 1.600+ famílias | Qualquer projeto — sem custo |
| **Proprietária de sistema** | SF Pro (Apple), Segoe UI (Microsoft) | SÓ apps nativos da plataforma |
| **Comercial (licença paga)** | Gotham, Söhne, GT America, Circular | Depende da licença (desktop, web, app) |
| **Custom (proprietária exclusiva)** | Netflix Sans, Airbnb Cereal | SÓ a empresa dona |

**Regra:** se o projeto tem ORÇAMENTO ZERO, use Google Fonts. Inter, Lato, Open Sans, Montserrat, Source Serif, Fraunces — todas gratuitas e de altíssima qualidade.

**Se o projeto TEM orçamento:** invista em uma fonte comercial para HEADLINES (Söhne, GT America, Circular). Para body text, Inter ou Open Sans resolvem.

## PASSO 6: Performance (2 min)

### Essa fonte vai CARREGAR rápido?

**Checklist de performance (Loop 11):**

- [ ] WOFF2 apenas (delete TTF, OTF, EOT)
- [ ] `font-display: swap` em todas as fontes de texto
- [ ] Preload da fonte crítica (1-2 no máximo)
- [ ] Subsetting — remova glifos que não usa
- [ ] Self-host (não use Google Fonts CDN em produção)
- [ ] Variável se 3+ pesos
- [ ] Font metric overrides (Fontaine) para CLS = 0
- [ ] Cache headers `immutable, max-age=31536000`

**Se é um app mobile:** a fonte JÁ ESTÁ no dispositivo (SF Pro, Roboto). Use `system-ui`. Zero download.

---

## PASSO 7: Acessibilidade (2 min)

### Todo mundo CONSEGUE ler?

**Checklist de acessibilidade (Loop 14):**

- [ ] Body text ≥ 16px
- [ ] Contraste ≥ 4.5:1 (texto normal), ≥ 3:1 (texto grande)
- [ ] Line height ≥ 1.5× no body
- [ ] Linhas de 45-90 caracteres (max-width: 65ch)
- [ ] Alinhado à esquerda (não justified)
- [ ] Sans-serif para body text
- [ ] Distinção clara entre l/1/I, 0/O, b/d
- [ ] Funciona a 200% zoom
- [ ] Usuário pode trocar a fonte
- [ ] Funciona em dark mode

**A regra de ouro da acessibilidade:** se você precisa apertar os olhos para ler seu próprio texto, ALGO está errado. Aumente o tamanho, o contraste, ou ambos.

## Exemplos de Aplicação do Framework

### Exemplo 1: App de Finanças Pessoais

| Passo | Decisão |
|---|---|
| **1. Contexto** | App mobile (iOS + Android), ~500 palavras por tela, público geral, 16-60 anos |
| **2. Personalidade** | Confiança + clareza. "Seu dinheiro está seguro aqui." |
| **3. Categoria** | Neo-Grotesca. Neutra, limpa, profissional. |
| **4. Pairing** | 1 fonte. **Inter** — 9 pesos cobrem toda a hierarquia. |
| **5. Licença** | Gratuita (OFL). Sem custo. |
| **6. Performance** | `system-ui` stack. SF Pro no iOS, Roboto no Android. Zero download. |
| **7. Acessibilidade** | Inter tem x-height alta, apertures grandes. Body a 16px. Contraste validado. |

**Decisão final:** `system-ui` stack com Inter como fallback premium.

### Exemplo 2: Blog de Culinária

| Passo | Decisão |
|---|---|
| **1. Contexto** | Site desktop + mobile, artigos de 1.000-3.000 palavras, público feminino 25-55, fotos de comida |
| **2. Personalidade** | Calor + elegância acessível. "Cozinhar é amor." |
| **3. Categoria** | Serif para headlines (elegância) + Sans para body (legibilidade) |
| **4. Pairing** | **Playfair Display** (headlines) + **Lato** (body). Didone elegante + humanista quente. |
| **5. Licença** | Ambas gratuitas (Google Fonts). |
| **6. Performance** | WOFF2, swap, preload da Playfair (headline acima da dobra), subset Latin |
| **7. Acessibilidade** | Lato a 17px, line-height 1.6. Playfair só em headlines grandes (≥24px). Contraste validado. |

**Decisão final:** Playfair Display Bold (headlines) + Lato Regular (body).

### Exemplo 3: Dashboard de Analytics Enterprise

| Passo | Decisão |
|---|---|
| **1. Contexto** | Web app desktop, telas densas com tabelas e gráficos, analistas de dados, 8h/dia de uso |
| **2. Personalidade** | Precisão + neutralidade. "Os dados falam por si." |
| **3. Categoria** | Neo-Grotesca para UI + Monospace para números/dados |
| **4. Pairing** | **IBM Plex Sans** (UI) + **IBM Plex Mono** (tabelas, números). Superfamília. |
| **5. Licença** | Ambas gratuitas (OFL). |
| **6. Performance** | Self-hosted WOFF2. Subsetting agressivo (só caracteres usados). |
| **7. Acessibilidade** | Plex Mono com distinção clara 0/O, 1/l/I. Contraste ≥4.5:1 em todas as labels. |

**Decisão final:** IBM Plex Sans (UI) + IBM Plex Mono (dados).

### Exemplo 4: Marca de Moda de Luxo

| Passo | Decisão |
|---|---|
| **1. Contexto** | Site + Instagram + embalagem, headlines e logos, público feminino 25-40, aspiracional |
| **2. Personalidade** | Elegância + exclusividade + glamour. "Isso é PARA POUCOS." |
| **3. Categoria** | Didone (Bodoni/Playfair DNA). Contraste extremo, serifas sem bracket. |
| **4. Pairing** | **Bodoni** (logo, headlines) + **Montserrat Light** (body mínimo). |
| **5. Licença** | Bodoni Moda (Google Fonts, gratuita) ou Bodoni comercial. Montserrat gratuita. |
| **6. Performance** | Bodoni só em tamanhos GRANDES (32px+). Body em Montserrat a 14px. |
| **7. Acessibilidade** | ⚠️ Bodoni em body seria um DESASTRE. Só em headlines grandes. Body SEMPRE em sans-serif legível. |

**Decisão final:** Bodoni Moda (logo/headlines) + Montserrat Light (body).

## A Regra Final: "Quando Em Dúvida, Use Inter"

Este guia tem 17 loops, ~450 KB, centenas de fontes citadas. Mas se você chegou até aqui e ainda está EM DÚVIDA:

**Use Inter.**

Inter é:
- Neo-grotesca neutra (funciona em 80% dos contextos)
- x-height altíssima (legível a 11px)
- 9 pesos (hierarquia COMPLETA)
- Variável (1 arquivo, performance máxima)
- Open source (zero custo)
- Google Fonts CDN (zero configuração)

**Inter não é a melhor fonte do mundo. Mas é a melhor "fonte padrão" do mundo.** Comece com Inter. Quando o projeto tiver personalidade suficiente para JUSTIFICAR uma escolha diferente, aí sim — volte para este guia e escolha com intenção.
